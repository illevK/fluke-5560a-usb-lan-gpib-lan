# 교정자동화 v1

기존 Fluke 교정기 v6.10.38과 별도로 실행하는 Windows 데스크톱 프로그램입니다.
기존 바탕화면 파일과 설정을 교체하지 않습니다.

[사용 안내](사용안내.md) · [1.0.5 배포 기록](release_v1.0.5.json) · [설계 및 장비 확장](ARCHITECTURE.md)

## 실행 및 개발

`python app.py`로 실행합니다. 의존성은 `requirements.txt`에 있습니다.
`python -m unittest discover -s tests -t .`로 관련 검사를 실행합니다.
`python build.py`는 콘솔 없는 `dist/교정자동화.exe`를 만듭니다.
`python verify_release.py`는 최종 EXE를 장비 연결 없이 검사합니다.
빌드는 기존 프로그램이나 장비에 접속하지 않습니다.

## 구조

- `domain`: 측정값·단위·붙여넣기·장비별 출력 범위·채널 및 실행 계획
- `instruments`: USB/VISA, GPIB, RS232, LAN 전송과 제조사 명령
- `services`: 장비 드라이버 계약, 연결 서비스, 측정 상태 머신, 저장
- `ui`: Qt 모델/뷰 측정표와 화면. 장비 명령은 화면 코드에 넣지 않습니다.

v6.10.38에서 통신과 파서를 소스 모듈로 옮겼으며 출처 해시는 `baseline.json`에 있습니다.
새 빌드는 `.pyfrag`, 문자열 치환, 기존 exe 또는 기존 Python 파일에 의존하지 않습니다.
기존에 해결했던 응답 구분, COM 설정, VISA 소유권, STBY 확인 및 단자 설정을 유지합니다.
새로운 장비는 드라이버 레지스트리에 식별·준비·새 값 읽기를 등록합니다.

장비 I/O는 작업 스레드에서 순서대로 실행합니다. 화면은 이벤트만 받습니다.
측정 중 정지 요청은 기준기 전용 STBY 작업을 깨웁니다. DUT 읽기가 지연되어도 기준기에
정지를 요청하며, 기준기 잠금과 OPER 차단으로 같은 포트의 명령이 겹치지 않게 합니다.
출력 유지 상태에서도 실제 출력 여부를 확인하며, 정지는 대기를 취소하고 STBY를 확인합니다.
장비가 끊어지면 다음 행으로 가지 않습니다. 복구해도 OPER를 자동으로 재전송하지 않습니다.
입력 오류 행도 보존하며, 실행 시 해당 행에서 정지합니다.

설정·자동 복구 측정표·기본 로그는 `%LOCALAPPDATA%/CalibrationAutomation`에 저장합니다.
설정에서 로그 폴더를 변경할 수 있습니다. 측정표와 원본 측정값은 JSON으로 저장할 수 있습니다.
표시와 복사는 명목값 단위를 따르며, 미리보기 결과는 실제 측정값과 구분됩니다.

장비 인터페이스는 본체가 실제 지원하는 인터페이스만 사용합니다.
USB 또는 LAN 커넥터의 존재만으로 임의 장비를 지원하는 것은 아닙니다.
새 모델은 명령과 응답 계약을 검증한 뒤 추가합니다.
