## 변경 내용

측정표와 DUT 연결을 중심으로 화면을 다시 만들었습니다. 빈 표로 시작하고,
세부 연결/측정 설정은 별도 창으로 정리했습니다. 짧은 진행률·로그 패널 효과는 설정에서 끌 수 있습니다.
표는 필요한 셀만 표시하는 Qt 모델/뷰 구조이며 행마다 입력 위젯을 만들지 않습니다.
새 GUI 실행 환경을 포함하므로 EXE 용량은 기존 14.6 MB보다 커졌습니다.
브라우저 실행 환경은 포함하지 않습니다. 소스·장비 통신·실행 순서·저장·UI를 분리했습니다.

장비를 재연결해도 출력을 자동으로 재개하지 않습니다. 보호 오류와 통신 실패를 구분하고,
STBY를 실제로 확인하지 못한 경우 출력 상태 미확인으로 표시합니다. 측정 중 정지는
DUT 응답 지연과 별도로 기준기에 STBY를 요청합니다. 정지 후 도착한 값은 기록하지 않습니다.

## 확인 결과와 범위

- 단위/파서, 통신 프레이밍·타임아웃·VISA 소유권, 장비 명령, 새 실행 엔진, 연결 서비스,
  Qt 화면을 포함한 **181건 통과**.
- 새 엔진에서 DUT 기능 변경이 출력보다 먼저 이루어지는지, 3 A 단자 선택,
  4개 기준기 모델의 저항 널 및 보상 OFF, 보호 오류 후 연결 유지 확인.
- DUT 읽기가 막혀 있어도 정지 요청으로 기준기가 STBY가 되는지, 늦은 값이 기록되지 않는지 확인.
- 3,000행 표, 선택 채널 실행, 복사·입력·정렬/원복·저장 복구 확인.
- 최종 EXE로 빈 초기 화면, 화면 이미지 생성, 가상 DC→AC 측정과 종료 STBY 확인.
- 콘솔 없는 실행 파일 형식, 파일 버전, Windows 표시 플러그인 및 통신 모듈 포함 확인.
- 이 PC에서 EXE 시작부터 화면 생성과 가상 2행 측정 종료까지 3.5초. 성능 보장값은 아닙니다.
