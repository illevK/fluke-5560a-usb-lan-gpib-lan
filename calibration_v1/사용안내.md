# 교정자동화 사용 안내

**문서 → 교정자동화 배포본 → 교정자동화.exe**를 실행합니다. 버전은 창 상단에 표시됩니다.
같은 장비에 연결할 때는 먼저 다른 프로그램에서 그 장비의 연결을 해제합니다.
시작 화면은 빈 측정표입니다. 설정과 측정표를 불러와도 자동으로 출력하지 않습니다.

## 연결과 실행

1. 상단 기준기와 DUT의 **연결**을 누릅니다. 기본 AUTO는 지원되는 USB, COM, GPIB 및 LAN 연결을 찾습니다.
2. 처음 연결하는 LAN 장비를 찾지 못하면 해당 장비의 **설정**에서 본체 IP와 서브넷 마스크를 입력합니다.
   PC와 직결이면 **유선 직결**을 켭니다. 유선 인터페이스를 확인해 주소와 경로를 맞추며,
   Windows 네트워크 변경이 필요한 경우 Windows 관리자 확인창이 나타날 수 있습니다.
3. 연결된 모델과 포트를 확인합니다. 여러 DUT가 응답하면 선택창이 표시됩니다.
   **DUT 설정 → 장비 모델**에서 Yokogawa WT, N4L PPA, Hioki PW 계열 또는
   34401A·34461A·34465A를 지정하면 해당 장비를 찾아 연결합니다.
   장비마다 실제로 제공하는 인터페이스와 본체 REMOTE/HOST 설정을 사용해야 합니다.
   Fluke 5730A는 **기준기 설정 → 장비 모델 → 5730A**에서 선택할 수 있습니다. 본체의
   **Setup Menu → Instrument Setup → Remote Port → Active Remote Port**를 사용할 포트로 맞춥니다.
   USB 직결은 후면 USB Device 포트를 사용하며 Windows에서 가상 COM으로 인식합니다.
   LAN은 본체 IP와 소켓 포트(기본 3490), RS-232는 널모뎀 케이블과 본체 통신 설정,
   GPIB는 VISA 드라이버가 설치된 어댑터를 사용합니다.
4. 엑셀에서 마지막 열을 명목값으로 두고 복사한 뒤 **붙여넣기 +**를 누릅니다.
   이 버튼은 항상 표 아래에 이어 붙입니다. DC·AC 전압/전류/전력과 역률을 함께 넣을 수 있습니다.
5. 필요한 경우 **채널 배정 → 배정 미리보기 → 배정 적용**을 사용합니다.
6. **측정 설정**에서 유지시간, 전류 그룹, 턴코일, 전류 듀얼 출력 등을 지정합니다.
7. 시작 행을 선택하고 **시작**을 누릅니다. 같은 채널·선택 그룹 안에서 행별로 DUT 설정,
   기준기 출력, 안정화, 새 값 읽기, 기록이 이어집니다.

잘못된 입력이나 출력 한계 초과 행도 붙여넣어집니다. 실행은 해당 행에서 중단되고
다음 행을 출력하지 않습니다. 명목값·조건을 고친 뒤 다시 시작할 수 있습니다.

### AUTO에서 기준기를 찾지 못했을 때

검색이 끝나면 기준기 연결 설정이 열립니다. **장비 모델 → 연결 방식**을 고르면
**본체에서 확인**에 메뉴와 단자가, **PC에서 설정**에 주소나 통신 조건이 나옵니다.
**시도 기록**에서 오류 전문을 볼 수 있습니다. 설정을 맞춘 뒤 **다시 연결**을 누릅니다.
예를 들어 5522A에 USB–RS232 케이블을 쓰면 **5522A → RS232**를 선택합니다.
후면 **SERIAL 1 FROM HOST**, 본체 **HOST serial**과 **REMOTE I/F comp**를 확인합니다.
기준기 설정은 평소에도 상단의 **설정**에서 열 수 있습니다.

**지난 연결 설정**에는 실제 장비의 식별과 출력 상태 조회가 모두 성공한 뒤,
모델·일련번호·연결 방식별로 마지막 주소, 통신 조건, 응답 및 출력 완료 제한 시간이 저장됩니다. 기록을 고르면 세부 값이 보이고,
**이 설정 불러오기**로 입력칸에 적용합니다. 이전 버전의 주소 기록에는 일련번호와 시각이 없다고 표시합니다.
직결 여부와 마스크가 미기록인 LAN 장비는 현재 직결 선택과 마스크를 본체 설정과 대조하세요.

## 단자와 채널

- 5730A 본체는 DC·AC 전압, DC·AC 전류, 고정 저항을 출력합니다. 전류는 NORMAL(OUTPUT HI/LO) 단자로
  최대 2.2 A를 사용합니다. 외부 증폭기 출력, 전력·역률처럼 전압과 전류가 동시에 필요한 행은 실행 전에 표시됩니다.

- 5560A 전류 듀얼 출력은 **측정 설정 → 작은 전압을 함께 출력**에서 켭니다.
  DC/AC 보조 전압을 각각 입력할 수 있습니다. 듀얼 출력 지원 범위도 실행 전에 확인합니다.
- 전류 그룹은 장비의 실제 단자 기준 또는 작업 기준 3 A 이상으로 나눌 수 있습니다.
  **더보기 → 현재 전류 그룹을 위로 정렬 / 원래 순서로 복원**을 제공합니다.
- 34461A와 34465A는 3 A 미만은 3 A 단자, 3 A부터는 10 A 단자 기준입니다.
  프로그램이 내부 단자를 설정하고 응답을 확인합니다. 실제 리드는 STBY에서 옮깁니다.
- 채널의 반복 조건을 미리 보고 배정합니다. 실제 채널보다 많은 구간은 선택한 물리 채널을
  다시 쓰는 `3@`, `2@` 등으로 구분합니다. 채널 또는 전류 단자·결선이 바뀌는 지점에서는 STBY로 멈춥니다.
- CH2의 행을 선택해서 시작하면 남아 있는 CH1로 되돌아가지 않습니다.
- **진행 보류 · 출력 유지**는 자동 진행만 보류합니다. **정지 · STBY**는 출력을 끄고 확인합니다.

## 측정값과 저장

- **내용 지우기**를 누르면 현재 표의 행과 측정값을 비웁니다. 장비 연결과 측정 설정을 유지하며,
  새 내용을 붙여넣으면 1행부터 시작합니다. 실수로 비웠다면 빈 화면에서 **이전 작업표 복구**를 누르세요.
- 기본 유지시간은 3.5초입니다. 표시·복사 단위는 각 행의 명목값을 따릅니다.
- 기준기만 연결하면 기본은 **자동 진행 · 자유 입력**입니다. 유지시간이 지나면 측정값이 비어 있어도
  같은 채널·그룹의 다음 행을 출력합니다. 측정값은 진행 중이나 종료 후에 원하는 행에 입력하세요.
  Enter는 값을 저장하고 한 칸 아래로 이동합니다. 결선 변경 지점에서는 STBY로 멈춥니다.
- 한 행씩 확인하려면 **측정 설정 → 직접 입력 진행 방식 → 입력 대기 · Enter로 진행**을 선택합니다.
  출력 안정화 후 해당 행의 값과 Enter를 기다립니다. 입력 중 **정지 · STBY**를 누르면 출력을 끕니다.
- DUT를 연결하고 **DUT 연결 시 측정값 자동 기록**을 켜면 장비에서 새 값을 읽어 기록합니다.
- 측정값 셀 일부를 드래그해 Ctrl+C로 복사하거나, 측정값 열 제목을 눌러 전체를 복사합니다.
  빈 측정값도 행 위치가 유지되도록 복사합니다. 우클릭에는 선택 행부터 마지막까지 복사가 있습니다.
- 설정 메뉴에서 측정값 열 표시, 화면 효과, 로그 저장 폴더를 바꿉니다.
- 저장/열기는 측정 조건·원본 측정값·채널 배정·그룹 설정을 함께 보존합니다.
  자동 복구 파일은 `%LOCALAPPDATA%\CalibrationAutomation\autosave.json`입니다.
  첫 화면의 **이전 작업표 복구**로 불러오며 자동 실행하지 않습니다.
- CSV 내보내기는 표시 단위가 적용된 표를 저장합니다.

## 저항과 연결 오류

34461A와 34465A의 저항 자동 측정은 2선식, 기준기 보상 OFF를 사용합니다. 시작 시 0 Ω를 출력해
DUT 널값을 설정·확인한 다음 측정 행을 진행합니다. 0~10 MΩ 조건을 포함해 장비별 범위를 검사합니다.

보호 동작이나 응답 오류가 있으면 다음 행으로 진행하지 않습니다. 응답 가능한 연결은 유지하고
STBY 확인 결과를 표시합니다. 통신이 끊겨 확인하지 못하면 **출력 상태 미확인**으로 표시합니다.
이때 실제 본체에서 상태를 확인해야 합니다. 설정 메뉴의 **같은 장비 연결 복구 · STBY**는
동일 장비를 확인한 뒤 복구하며, 출력 재개는 시작 버튼으로 합니다.

## 장비 없이 확인

장비 연결을 해제한 뒤 **설정 → 장비 없이 미리보기**로 화면과 진행 흐름을 확인할 수 있습니다.
가상 결과에는 `[미리보기]`가 표시되며, 실제 장비와 가상 장비를 혼합해 실행할 수 없습니다.
이번 버전의 자동 검사는 가상 장비와 메모리/로컬 통신으로 수행했습니다.
실물 장비 조합별 측정 정확도와 연속 출력 시험은 별도로 확인해야 합니다.
