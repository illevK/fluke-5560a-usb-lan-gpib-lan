# 교정자동화 v1 작업 규칙

이 폴더가 새 `교정자동화.exe`의 소스입니다. 기존 `outputs/fluke_5560a_controller.py`,
`work/*.pyfrag`, 바탕화면 `Fluke 교정기.exe`는 별도 프로그램입니다.
사용자가 기존 프로그램 정리를 요청하기 전에는 새 프로그램으로 덮어쓰거나 삭제하지 않습니다.

- 진입점은 `app.py`, 배포 빌드는 `build.py`, 패키지 실행 검사는 `verify_release.py`입니다.
- UI에 장비 명령을 넣지 않습니다. DUT 식별/연결은 instruments/services, 행별 준비/측정은 드라이버,
  순서/정지/기록은 MeasurementEngine에서 처리합니다. `.pyfrag` 생성·문자열 치환 패치는 사용하지 않습니다.
- 새 DUT는 기능별 수동 조작 없이 행의 종류에 따라 설정하고 측정해야 합니다.
  지원되지 않는 기능/채널/단자는 기준기 출력 전에 차단합니다.
- 출력 상태 미확인을 STBY로 표시하거나, 연결 복구 후 OPER/다음 행을 자동 재전송하지 않습니다.
  오류의 늦은 응답을 정상 값으로 기록하지 않습니다. 시뮬레이션 값에는 출처 표시를 유지합니다.
- 붙여넣기 입력 오류/범위 초과 행은 보존합니다. 표시·복사 단위는 명목값 단위입니다.
  측정 원본 숫자와 단위를 저장하고 표시 과정에서 반올림/분해능을 임의로 적용하지 않습니다.
- 작은 수정은 관련 기능만 검사합니다. 실행 엔진/통신 공통부 또는 전체 재설계는 관련 회귀 범위까지 검사합니다.
  단순히 작업을 마칠 때마다 모든 검사를 반복하지 않습니다.
- 실제 장비 시험 여부와 모의 시험 여부를 구분해 보고합니다. 소프트웨어 검사를 실물 검증으로 표현하지 않습니다.
- EXE를 만들 때 `build.py`의 격리된 PATH 정책을 유지합니다. 패키징 후 최종 EXE 자체도 확인합니다.
- 배포한 파일의 버전/해시와 확인 항목을 기록합니다. 수정 요청이 없던 기존 프로그램 파일은 보존합니다.
- 배포 파일명은 `교정자동화.exe`로 통일합니다. 버전은 창 제목과 Windows 파일 속성에서 확인합니다.
