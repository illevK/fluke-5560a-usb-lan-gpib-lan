# Fluke Controller · DUT 연결과 측정값 자동 기록

## 측정값 복사

- 측정표의 **측정값 · 전체 복사** 제목을 클릭하면 첫 행부터 마지막 행까지 복사합니다.
- 측정값 셀을 우클릭하면 **현재 행부터 끝까지 복사**할 수 있습니다.
- 기존 드래그 선택 후 Ctrl+C도 유지됩니다. 빈 행을 보존하고 각 행의 명목값 단위로 결과를 복사합니다.
- 일반 셀 클릭은 입력을 위한 동작입니다. 입력하려고 클릭할 때마다 클립보드가 바뀌지는 않습니다.

## DUT 연결 탭

상단 연결 버튼은 Fluke 기준기용입니다. **DUT 연결** 탭을 처음 열면 USB, LAN과 USB COM의 DUT를 검색합니다.
지원 장비 한 대가 확인되면 바로 연결하고, 여러 대면 목록에서 장비를 선택합니다.
연결 후 입력 채널을 선택하세요. **한 번 읽기**와 **자동 조회**는 이 탭에서 값을 확인하는 기능입니다.
자동 조회 간격은 직전 조회가 끝난 시점부터 계산합니다. 조회가 겹치지 않습니다.
연결할 때 모델별 빠른 갱신, 전압 기준, 전압·전류 자동 범위를 설정하고 읽어서 확인합니다. WT는 RMS를 사용하며,
본체의 첫 네 항목을 전압, 전류, 유효전력, 역률로 맞춥니다. 여러 입력을 사용하는 모델에서는 첫 활성 채널이 본체 표시의 기준입니다.

## 측정표에 자동 기록

첫 표는 **표 편집 → 전체 새로 붙여넣기**로 넣고, 다음 표부터 **끝에 붙여넣기**로 추가합니다.
같은 결선으로 측정할 행을 모은 뒤 **처음부터**를 누르면 1행부터 마지막 행까지 현재 전류 그룹을 순서대로 실행합니다.

- 실제 Fluke와 DUT를 연결한 뒤 **측정표** 탭에서 **DUT 자동 기록**을 켜고 행을 실행합니다. 처음에는 켜져 있습니다.
- 해당 행의 출력과 OPER가 확인되면 기존 유지시간을 기다리고, DUT에서 새로 갱신된 값을 가져와 **측정값**에 넣습니다. 전압·전류·유효전력·역률 중 행에 해당하는 값만 기록합니다. 저항 행은 수동으로 입력합니다.
- 전류 그룹과 행 순서, 턴코일 설정을 따릅니다. DUT 원본 수치를 보관하고, 측정값 표시와 복사는 명목값 단위로 환산합니다. 예를 들어 명목값이 0.6 kW이고 DUT 값이 599.8 W이면 0.5998 kW로 표시합니다. 환산에는 반올림을 적용하지 않습니다. 단위 없이 입력한 수치는 입력 시점의 명목값 단위로 저장합니다. DUT의 전류 값에는 턴코일 비율을 다시 곱하지 않습니다.
- 5560A AC 전압 행은 기존 오류를 조회하고 출력 설정을 확인한 뒤 OPER를 요청합니다.
- DUT 오류 또는 유효한 수치가 없는 경우 그 행에 값을 쓰지 않고 자동 진행을 중단합니다. 가상 장비의 값은 측정표에 자동 기록하지 않습니다.
- DUT의 평균·필터 설정은 그대로 사용합니다. 이 설정이 이전 출력의 영향을 오래 유지한다면 측정표에서 유지시간을 늘리세요. WT 본체의 HOLD와 WT310 계열의 MAX HOLD는 해제하세요. WT3000 계열에서 직류 전압·전류를 기록하려면 DUT 연결 후 해당 입력 모드를 DC로 맞추세요.

프로그램의 표시 순서는 전압, 전류, 유효전력, 역률, 피상전력, 무효전력, 주파수입니다.
WT3000·WT3000E의 전압과 전류는 본체 측정 모드를 조회해 RMS, DC, MEAN, RMEAN으로 함께 표시합니다.
수신 시각과 채널을 함께 표시합니다. 5초가 지나거나 다음 조회가 시작되면 기존 값은 ‘이전 수신값’으로 표시합니다.
통신 오류가 나면 자동 조회를 멈추고 표시값을 비웁니다. 정상 수치가 아닌 NAN/INF/범위 초과는 ‘—’로 표시합니다.

**미리보기 · 가상 DUT**는 고정 예제 데이터입니다. 실제 측정 결과가 아니며 화면에도 이를 표시합니다.

## 모델 범위

| 모델군 | 이번 버전에 등록한 명령 프로필 |
|---|---|
| N4L PPA | 5xx(510·550 포함), 15xx, 25xx, 26xx, 35xx, 45xx, 55xx(5511·5531 포함) |
| Yokogawa WT300 | WT310, WT310HC, WT332, WT333 |
| Yokogawa WT300E | WT310E, WT310EH, WT332E, WT333E |
| Yokogawa WT500 | WT500 / 760201·760202·760203 식별 응답 |
| Yokogawa WT1800 | WT1800(E) / WT1801~1806(E) 식별 응답 |
| Yokogawa WT3000 | 760301·760302·760303·760304 및 옵션 접미사가 붙은 식별 응답 |
| Yokogawa WT3000E | WT3001E·WT3002E·WT3003E·WT3004E 및 옵션 접미사가 붙은 식별 응답 |
| Yokogawa WT5000 | WT5000, 입력 슬롯 1~7 중 장착된 슬롯 선택 |

이는 공식 문서의 명령 형식을 구현한 범위이며, 모든 모델의 실물 호환 시험을 마쳤다는 의미는 아닙니다.
WT310E는 이 PC에서 NI-VISA USB 연결, 식별 및 값 조회를 확인했습니다. 이번 자동 기록 기능은 모의 통신으로 검증했습니다. 실제 모델의 펌웨어·통신 옵션에 따른 확인은 남아 있습니다.
미등록 N4L PPA는 장비 식별과 공통 RMS·전력 응답 형식을 확인한 경우 1번 채널을 조회할 수 있습니다. 모델별 기본값 적용과 측정표 자동 기록은 등록된 프로필에서 지원합니다.
모델별 실제 장착 채널과 설정된 결선에 맞춰 채널을 선택하세요. PPA5511은 1번 채널을 사용합니다.

## 연결 방법

| DUT 연결 방식 | 프로그램에서 선택 | 입력 |
|---|---|---|
| 자동 검색 | 자동 · USB / LAN / COM | VISA USB, LAN, USB COM의 일반 설정을 확인. 검색에서 빠진 장비는 주소와 본체 통신 설정을 직접 입력 |
| WT310 계열·WT500·WT1800·WT5000 USB 또는 GPIB | USB / GPIB · VISA | 목록에 나온 VISA 리소스와 해당 장비 드라이버 |
| WT310 계열·WT5000 등 VXI-11 LAN | LAN · WT | 본체 IP 주소와 VISA 드라이버 |
| WT5000 소켓 LAN | LAN · WT5000 TCP | 본체 IP 주소. TCP 10002와 LF. 소켓 통신 지원 펌웨어 |
| WT3000·WT3000E GPIB | USB / GPIB · VISA | 목록의 GPIB 리소스와 본체 주소 확인 |
| WT3000·WT3000E RS232 옵션 | COM · USB / RS232 | 본체와 속도·데이터·패리티·정지·흐름·줄 끝을 일치 |
| PPA USB | COM · USB / RS232 | 제조사 드라이버 설치 후 할당된 COM 포트 |
| PPA LAN | LAN · PPA | 본체 IP 주소. 기본 포트 10001, 변경한 경우 통신 설정에서 수정 |
| RS232 / PC USB–RS232 변환기 | COM · USB / RS232 | COM 포트와 본체와 일치하는 통신 설정 |
| PPA GPIB | USB / GPIB · VISA | GPIB 리소스. 본체의 GPIB 옵션/어댑터 필요 |

VISA 연결에는 NI-VISA 등 설치된 VISA 드라이버가 필요합니다. USB가 VISA 목록에 표시되지 않으면 해당 제조사의 USB 드라이버와 VISA 인식 상태를 확인하세요.
WT310E를 USB로 연결할 때는 본체에서 **INTERFACE → usb**를 선택합니다. 연결 후 **DUT 연결 → 자동 검색**을 다시 누를 수 있습니다. [WT310E 통신 매뉴얼](https://cdn.tmi.yokogawa.com/IMWT310E-17EN.pdf)
WT5000의 **Utility → Remote Control → Command Type**은 `WT5000`으로 설정합니다. [WT5000 통신 매뉴얼](https://cdn.tmi.yokogawa.com/1/7114/files/IMWT5000-17EN.pdf)

WT3000·WT3000E의 LAN과 USB에는 요꼬가와 TMCTL 전용 통신이 필요합니다. 이 프로그램의 WT3000 계열 연결은 GPIB와 장착된 RS232를 지원합니다. [WT3000 통신 매뉴얼](https://cdn.tmi.yokogawa.com/IM760301-17E.pdf) · [WT3000E 통신 매뉴얼](https://cdn.tmi.yokogawa.com/1/6259/files/IMWT3001E-17EN.pdf)

PPA의 USB는 일반적인 WT USBTMC와 다르므로 **COM 방식**을 사용합니다. [N4L CommView2 공식 안내](https://www.newtons4th.com/doc/D000260-CommView2-Manual-v3.1.pdf)

PPA55xx의 RS232 기본값은 19200 / 8-N-1 / RTS/CTS입니다. 본체 REMOTE에서 실제 연결에 맞게 USB 또는 RS232를 선택합니다.
PPA USB/RS232/LAN 송신 줄 끝은 CR 또는 CRLF, GPIB는 LF를 사용합니다.
WT는 기본적으로 LF를 사용합니다. RS232 속도·흐름·데이터 형식은 본체와 일치시켜야 합니다.
수동 COM 연결의 초기값은 9600 / 8-N-1 / RTS/CTS / CRLF입니다. **목록**에서 COM 포트를 고른 뒤 실제 설정과 맞추세요. COM 연결에는 pyserial과 변환기 드라이버가 필요합니다.
[PPA55xx 통신 문서](https://www.newtons4th.com/doc/PPA5500-Comms-Manual-v7.0.pdf), [PPA LAN 포트 안내](https://www.newtons4th.com/doc/PSM-and-PPA-LAN-connection-Issue-2-Jan-2010.pdf)

## 조회 시 동작과 현재 제한

- PPA는 본체의 ASCII 자릿수를 그대로 사용하며 POWER 명령으로 전력 분석값을 조회합니다. RMS와 전력은 순서대로 읽습니다.
- DUT 연결 시 모델에 맞는 빠른 갱신 주기, 전압 동기, 전압·전류 자동 범위를 설정하고 장비 응답을 확인합니다. WT310/332/333 및 WT3000 계열은 입력 모드도 RMS로 설정합니다. PPA는 기본 입력의 AC+DC 결합과 FAST 갱신을 적용합니다.
- WT는 통신 출력 항목을 지정하고 설정을 다시 읽어 확인한 뒤 조회합니다. 통신용 숫자 HOLD는 해제합니다. 배율과 적산 설정은 건드리지 않습니다. 연결 시 적용한 측정 설정과 통신 출력 항목·헤더·형식은 연결 해제 후에도 본체에 남을 수 있습니다.
- 주파수는 WT에서 전압 주파수(FU), PPA에서는 본체 전력 응답의 주파수입니다. 역률 부호는 본체 규칙을 그대로 사용하며 LEAD/LAG를 추정하지 않습니다.
- 본체에서 CT/PT·외부센서 배율 등을 적용했다면 그 응답을 그대로 표시합니다. Fluke의 턴코일 설정을 DUT 값에 다시 곱하지 않습니다.
- USB COM 자동 검색은 일반 설정만 시도합니다. PC 내장 COM 포트, 특수 속도·패리티를 사용하는 장비는 수동으로 설정합니다. LAN 자동 검색은 현재 네트워크의 VXI-11 응답과 VISA 목록을 사용합니다.
- 측정표 입력값과 DUT 연결 설정은 현재 실행 중에 유지됩니다. 종료 후 복원하는 저장 기능은 이번 변경에 포함되지 않습니다.
