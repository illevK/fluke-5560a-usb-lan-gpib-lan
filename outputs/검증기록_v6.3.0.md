# v6.3.0 측정값 구간 복사 — 2026-11-02 배포 확인

측정값 열의 연속된 행을 드래그로 선택하고 Ctrl+C 또는 우클릭 메뉴로 복사합니다. 선택 구간만 표의 위→아래 순서대로 복사하며, 빈칸·소수점 뒤 0·단위·메모를 유지합니다. 엑셀에는 한 열로 붙여넣을 수 있습니다.

- 선택 셀의 파란색 표시, 역방향 드래그, Shift+클릭/↑/↓ 범위 선택.
- 가장자리 자동 스크롤, 마우스 해제 시 스크롤 중지, Esc 선택 해제.
- 셀 내부 가로 드래그는 기존 글자 선택·복사를 유지합니다. Enter 이동과 측정값 입력은 계속 사용할 수 있습니다.
- 상태 갱신 시 선택 표시 유지. 열 숨김/표 교체 시 선택 해제.
- 기록 복사는 출력 설정이나 장비 명령을 변경하지 않습니다.
