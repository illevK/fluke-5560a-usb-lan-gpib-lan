# Fluke 교정기 제어 프로그램 v6.3.0

기존 전압·전류·저항·전력 출력, 시트 붙여넣기, 순차 실행·중단점·재개, 턴코일 환산, 전류 그룹 분리, 응답 대기 및 로그 기능을 네 모델에서 사용할 수 있도록 확장했습니다. 모델별로 불가능한 설정은 입력 또는 전송 단계에서 차단합니다.

## 가능한 연결

| 모델 | 장비 USB 직접 연결 | LAN | RS-232 / PC USB–RS-232 | GPIB / PC USB–GPIB |
|---|---|---|---|---|
| 5560A | USBTMC 지원 | 지원 | 지원 | 지원 |
| 5522A | 미지원 | 미지원 | 지원 | 지원 |
| 5520A | 미지원 | 미지원 | 지원 | 지원 |
| 5080A | 미지원 | 지원 | 지원 | 미지원 |

USB–RS-232 컨버터는 **RS232** 모드를 선택합니다. USB–GPIB 컨트롤러는 **GPIB** 모드를 선택합니다. **USB**는 5560A 후면 USB Device 포트의 USBTMC 직접 연결입니다. 장비의 USB 저장장치용 포트는 PC 원격 제어 포트가 아닙니다. 별도의 LAN–GPIB/시리얼 게이트웨이는 이번 지원 범위에 포함하지 않았습니다.

## 실행과 연결

1. 기존 프로그램을 종료하고 `Fluke 교정기.exe`를 실행합니다. CMD 창 없이 열리며 상단에 **v6.3.0**과 네 모델명이 보입니다. EXE 실행에는 `.py`/`.pyw` 파일이나 Python 설치가 필요 없습니다. NI-VISA와 컨버터 드라이버는 PC의 기존 설치를 사용합니다.
2. 연결할 **모델**을 먼저 선택합니다. 해당 모델에서 가능한 연결 방식만 목록에 표시됩니다.
3. 아래 방법으로 연결합니다. 실제 식별 응답의 제조사·모델이 선택한 모델과 일치해야 연결이 완료됩니다. 모델을 바꾸려면 먼저 연결을 해제합니다.

### RS232 / USB–RS-232 컨버터

- 컨버터 제조사의 Windows 드라이버를 설치한 뒤 **COM 찾기**를 누르고 해당 COM 포트를 선택합니다. COM 번호를 직접 입력해도 됩니다. 목록 조회는 포트를 열거나 장비에 명령을 보내지 않습니다.
- 기본 설정은 **9600 / 8 / N / 1 / XON/XOFF / CRLF**입니다. 본체 설정과 속도·데이터 비트·패리티·정지 비트·흐름 제어·EOL을 모두 맞추세요. 본체가 NONE/NOSTALL 또는 RTS/CTS이면 화면의 흐름 제어도 동일하게 변경합니다.
- 5522A·5520A는 **SERIAL 1 FROM HOST**에 연결합니다. **SERIAL 2 TO UUT는 PC 제어용 포트가 아닙니다.** PC와의 연결은 null-modem 결선을 사용합니다. 컨버터에 이미 교차 결선이 들어 있는지 확인해 중복 교차하지 마세요.
- 5560A·5080A도 해당 본체 설명서의 RS-232 커넥터·핀 배치에 맞는 케이블을 사용하고, 본체에서 RS-232 원격 포트를 활성화/선택해야 합니다.
- 5522A·5520A 속도 선택은 300~9600, 5080A는 300~115200, 5560A는 9600~115200 baud 중 각 모델이 지원하는 값입니다.
- 프로그램에서 pyserial이 없다고 나오면 `통신라이브러리_설치.cmd`를 실행하세요. 프로그램은 본체의 저장된 RS-232 속도·배선 설정을 자동 변경하지 않습니다.

### LAN

- 5560A·5080A의 **현재 IP와 포트**를 입력합니다. 기본 포트는 둘 다 3490이며, 본체에서 변경했으면 변경된 값을 입력하세요.
- PC 실제 랜카드를 선택하고 **LAN 진단**으로 식별 응답을 확인한 뒤 연결합니다. 5560A 기본 입력값 169.254.1.1이 모든 장비의 현재 주소라는 뜻은 아닙니다.
- 5560A: Ethernet 활성화, 허용 PC IP 범위, 현재 IP/마스크/포트를 확인합니다.
- 5080A: 본체의 **Remote Interface Port를 LAN**으로 선택해야 LAN 서버가 동작합니다. 5560A 전용 `COMM_MODE` 명령은 보내지 않습니다.
- 두 모델 모두 다른 프로그램의 LAN 연결을 닫고 사용합니다. 프로그램은 PC IP·DHCP·방화벽을 자동 변경하지 않습니다.

### USBTMC / GPIB

- PyVISA와 NI-VISA 또는 사용하는 컨트롤러 제조사의 VISA 드라이버가 필요합니다. `통신라이브러리_설치.cmd`는 Python 라이브러리만 설치하며 장치 드라이버는 설치하지 않습니다.
- 5560A USB: 후면 USB Device 연결 후 본체의 USBTMC를 활성화합니다. **USB** 모드로 연결하거나 VISA 리소스 칸에 `USB0::...::INSTR`를 입력합니다.
- GPIB: 본체의 GPIB 주소와 프로그램의 주소를 맞춥니다. 기본 컨트롤러는 GPIB0이며 다른 컨트롤러는 VISA 리소스에 `GPIB1::8::INSTR`처럼 정확한 값을 입력합니다. USB–GPIB도 동일합니다.
- **AUTO**는 선택 모델의 지원 포트만 확인합니다. 입력된 LAN 주소 → 명시한 COM 포트 → USB/GPIB 순서로 시도합니다. 임의의 모든 COM 포트를 탐색해 명령을 보내지는 않습니다. 사용 포트를 알고 있다면 해당 모드를 직접 선택하는 편이 빠릅니다.

## 전류 그룹과 턴코일

- 기본 **작업 기준: 3 A 이상**은 기존과 같습니다. `0.1, 1, 3, 5, 2 A`에서 큰 전류 옵션 OFF는 `0.1, 1, 2 A`, ON은 `3, 5 A` 순으로 실행합니다. 전류와 전력 모두 **코일 환산 후 실제 출력 A**로 분리합니다.
- **선택 모델의 실제 단자 기준**도 선택할 수 있습니다. 5560A는 AUX ≤3.1 A / 30A >3.1 A, 나머지 세 모델은 AUX <3 A / 20A ≥3 A입니다.
- 그룹 변경은 실행 중에 적용하지 않습니다. 연결 중에는 STBY 확인 후 그룹과 시작 위치를 바꾸며, 출력은 사용자가 다시 시작해야 합니다. 케이블은 본체의 STBY를 확인한 뒤 바꾸세요.
- 5522A·5520A·5080A 자동 생성 전류/전력 명령은 해당 전류의 AUX/A20 단자를 명시합니다. 5560A는 자동 단자 선택을 사용하며 지원하지 않는 `CUR_POST A20`을 보내지 않습니다.
- 실제 최대 전류는 5560A 30 A, 다른 세 모델 20.5 A입니다. 예를 들어 50턴 코일을 사용하면 100 A 목표는 실제 2 A입니다. 고전류 출력 시간·휴지시간 등은 각 본체의 제한을 따르며, 5560A의 연속 30 A 특성을 다른 모델에 적용하지 않습니다.

### 턴코일 LCOMP 자동 처리

| 모델 | AC 전류·AC 전력의 턴코일 보상 |
|---|---|
| 5560A | 단독 턴코일용 일반 `LCOMP` 명령 없음. 자동 전송하지 않음 |
| 5522A·5520A | 실제 전류 <0.33 A: 주파수 <440 Hz, 실제 전류 ≥0.33 A: 주파수 <1000 Hz에서 `LCOMP ON` |
| 5080A | 주파수 <65 Hz에서 `LCOMP ON` |

턴코일을 켜고 위 범위에 들어가면 자동 생성 명령에 `LCOMP ON`을 넣습니다. 지원 주파수 밖이거나 턴코일을 끄면 AC 명령에 `LCOMP OFF`를 넣습니다. DC에는 AC 보상 명령을 넣지 않습니다. 생성 명령 미리보기에서 ON/OFF를 확인할 수 있습니다. 수동 명령 칸은 사용자가 작성한 명령을 사용합니다.

외부 52120A용 `LCOMP_52120`은 사용하지 않습니다. 코일 자체의 허용 전류·주파수와 보상 가능 여부는 별개의 조건입니다.

## 모델별 출력 차이

- 5080A 저항은 **0 Ω와 18개 고정값**만 가능합니다: 각 Ω/kΩ/MΩ 단위의 1, 1.9, 10, 19, 100, 190. 예를 들어 500 Ω은 거부하며 가까운 값으로 바꾸지 않습니다. 실제 보정된 저항 출력값은 본체 표시/`OUT?`로 확인합니다.
- 자동 생성 저항 명령은 5522A·5520A에서 110 kΩ 이상, 5080A에서 1 MΩ 이상이면 `ZCOMP NONE`을 사용합니다. 5080A에서 보상 가능한 가장 큰 고정값은 190 kΩ입니다.
- 모델 변경 시 시트 명령을 다시 계산합니다. 새 모델에서 불가능한 행은 명령을 지우고 오류로 표시하며 실행 전에 안내합니다.
- 프로그램은 기본 전류·전압·저항 범위와 위 조건을 검사합니다. 모든 주파수별 출력 조합·부하·정확도 조건을 대신 판정하지는 않습니다. 본체의 `ERR?` 오류가 발생하면 순차 실행을 중단하고 STBY를 확인합니다.

## 대기·중단 및 검증 범위

일반 조회 기본 3초와 출력 완료 기본 60초를 분리했습니다. 완료 응답을 기다리는 중에 출력 명령을 재전송하지 않습니다. LAN·RS232 대기는 STBY 요청으로 중단할 수 있습니다. USB/GPIB는 VISA 드라이버의 읽기가 반환할 때까지 중단이 지연될 수 있습니다. 통신 실패 시 STBY를 시도한 뒤 연결을 닫으며 자동으로 출력 재개하지 않습니다. 상태 미확인은 본체에서 확인해야 합니다.

통신 기록은 실행한 Python 파일 옆 `logs` 폴더에 저장됩니다. 이번 버전은 실장비에 접속하거나 출력하지 않았습니다. 모의 LAN·시리얼·VISA 및 GUI 시험으로 검증하며, 실제 컨버터·장비 펌웨어·결선에 따른 연결과 출력은 현장 확인이 남아 있습니다.
