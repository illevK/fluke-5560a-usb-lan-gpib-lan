# v6.2.1 단일 EXE — 2026-10-30

`Fluke 교정기.exe` 하나로 실행하도록 패키징했습니다. Python, Tkinter, PyVISA 1.16.1, pyserial 3.5를 포함하며 CMD 창을 생성하지 않습니다. NI-VISA와 장치별 드라이버는 PC의 기존 설치를 사용합니다.

패키징: Python 3.14.2, PyInstaller 6.22.3, Windows 64비트, onefile/windowed. [PyInstaller 공식 문서](https://pyinstaller.org/en/stable/operating-mode.html)

검증:

- 소스나 `.pyw`가 없는 별도 폴더에 EXE 한 개만 복사하고 실행 확인 성공.
- 콘솔 창 핸들 0 확인. GUI v6.2.1 초기화 성공.
- 포함된 PyVISA/pyserial 불러오기 성공. PC의 `C:\WINDOWS\system32\visa32.dll` 초기화 성공.
- 1 kV 변환, 기준번호를 제외한 Lead 역률 표 변환, 측정값 입력 및 열 숨김/복원 확인.
- 로그가 EXE 옆 `logs`에 남는지 확인. 임시 압축 해제 폴더에 기록이 유실되지 않도록 수정.
- 실제 장비에는 연결하거나 출력 명령을 보내지 않았습니다.

결과 파일: `work/standalone_v6.2.1/check.json`.

바탕화면에는 EXE를 배치하고, 이전 `.pyw`와 바로가기는 정리했습니다. 이전 소스는 `fluke_5560a_controller_v6.2.0_backup.py`로 보관했습니다. 개발용 `.py`와 문서는 작업 폴더에 남아 있으며 EXE 실행에는 필요하지 않습니다.
