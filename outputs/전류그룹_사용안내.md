# 전류·전력 그룹별 실행

모델별 연결과 턴코일 LCOMP 설정은 [모델별 연결 안내](모델별_연결안내.md)를 참고하세요. **선택 모델의 실제 단자 기준**은 5560A에서는 3.1 A 초과, 5522A·5520A·5080A에서는 3 A 이상을 큰 전류 그룹으로 분리합니다. 세 구형 모델은 자동 생성 명령에서 AUX/A20 단자를 명시합니다. 아래 5560A 설명의 단자 경계를 다른 모델에 적용하지 마세요.

엑셀 시트 탭의 **큰 전류 그룹만 실행** 옵션과 분리 기준을 사용합니다. 시트 행을 지우거나 재정렬하지 않고 원래 순서로 해당 그룹만 실행합니다. 전류와 전력 모두 적용되며, 턴코일을 사용할 때는 코일 환산 후 5560A가 실제로 출력하는 전류의 절댓값으로 분류합니다.

| 기준 선택 | 옵션 OFF | 옵션 ON |
|---|---|---|
| 선택 모델의 실제 단자 기준: 5560A (기본) | 3.1 A 이하 (VI AUX) | 3.1 A 초과 (30A) |
| 선택 모델의 실제 단자 기준: 5522A·5520A·5080A (기본) | 3 A 미만 (AUX) | 3 A 이상 (20A) |
| 작업 기준: 3 A 이상 | 3 A 미만 | 3 A 이상 |

요청한 `0.1 A → 1 A → 3 A → 5 A → 2 A` 예시는 **작업 기준**에서 OFF일 때 `0.1 → 1 → 2 A`, ON일 때 `3 → 5 A` 순으로 실행됩니다.

5560A의 기본 단자 기준에서는 위 예시가 OFF `0.1 → 1 → 3 → 2 A`, ON `5 A`로 나뉩니다. 싱글과 듀얼 모두 3.1 A까지 전류 HI에 VI AUX를 사용합니다. 3.1 A를 초과하면 30A 단자를 사용합니다. [공식 사용 설명서](https://media.fluke.com/98e20aac-6ee7-4151-8b35-b2fb011adb6b_original%20file.pdf#page=53)

## 사용 순서

1. 분리 기준을 고르고 옵션 OFF로 첫 그룹을 실행합니다.
2. 그룹이 끝나면 프로그램이 STBY를 확인합니다. 본체 STBY를 확인하고 케이블을 변경합니다.
3. 옵션 ON으로 전환합니다. 연결 중에는 STBY를 다시 확인한 뒤 선택을 바꿉니다. STBY 확인에 실패하면 기존 그룹을 유지합니다.
4. 시작 버튼을 누르면 큰 전류 그룹만 원래 시트 순서대로 실행합니다. 그룹 변경 자체는 출력을 시작하지 않습니다.

그룹을 바꾸면 이전 진행 위치와 시작·중단 행 범위를 전체 시트로 초기화합니다. 앞쪽 대상 행을 놓치지 않도록 한 동작이며, 필요하면 시작 전에 범위를 다시 지정하세요. 순차 실행 중이거나 응답 대기 중일 때는 그룹 변경을 보류합니다.

자동 시작·재개·다음/이전 행·선택 행 단독 출력에 같은 필터가 적용됩니다. 제외된 행의 중단점은 실행을 멈추지 않습니다. 대상이 없는 범위에서는 출력 명령을 보내지 않습니다. 전압·저항 행은 OFF에서만 실행하며 ON에서는 제외합니다. 별도의 전류/전력 수동 탭과 수동 명령 창은 이 시트용 필터의 대상이 아닙니다.

전력은 명목 W 값만 보고 분류하지 않습니다. 생성된 OUT 명령의 실제 전류(A)를 사용하므로 전압·역률·턴코일 환산이 반영됩니다. 예를 들어 50턴 코일을 통해 목표 100 A를 만드는 행은 실제 출력 2 A이므로 작은 전류 그룹입니다.

## 5560A 싱글·듀얼 출력 그룹

**측정표 → 범위·그룹 설정 → 5560A 출력 그룹**에서 전류 범위와 별도로 출력 그룹을 고릅니다. **싱글 출력**에는 전압·저항과 싱글 전류가, **듀얼 출력**에는 전력·역률과 듀얼로 변환된 전류가 들어갑니다. **전체 출력**은 선택한 전류 범위 내에서 두 출력 그룹의 행을 포함합니다. **현재 그룹 위로**와 **원래 순서**는 두 조건을 적용한 행 목록을 기준으로 동작합니다.

측정표 상단에서 **전류 듀얼 출력**을 켜고 **범위·그룹 설정**에서 **듀얼 DC**와 **듀얼 AC** 전압을 입력한 뒤 **전압 적용**을 누르세요. `500 mV`, `0.5 V` 또는 단위 없이 `0.5`로 입력할 수 있습니다. 실행할 때의 기본값은 DC 10 mV와 AC 33 mV입니다. AC 듀얼 전류는 45~65 Hz에서 코일 환산 후 실제 전류가 1.2001 mA~20.5 A일 때 적용합니다. 다른 AC 전류 행은 싱글 출력 그룹에서 실행할 수 있습니다. [5560A 제품 사양, 본문 21쪽](https://media.fluke.com/421591d3-03b5-40c3-ad8c-b2d5016f30e9_original%20file.pdf#page=22)

듀얼 출력에서는 전류 리턴을 **SENSE LO**에 연결하고 싱글 전류에서는 **OUTPUT LO**를 사용합니다. 전류 HI는 실제 전류에 따라 VI AUX 또는 30A입니다. 변환된 전류 행은 STBY에서 전압·전류 설정을 조회한 뒤 OPER를 요청합니다. 그룹을 바꿀 때 본체 STBY와 결선을 확인하세요. [5560A 사용 설명서](https://media.fluke.com/98e20aac-6ee7-4151-8b35-b2fb011adb6b_original%20file.pdf)

## 검증

그룹 분류, 실행 순서와 STBY 전환을 모의 장비로 확인했습니다. 듀얼 전압·전류 설정이 조회 응답과 일치할 때만 OPER를 요청하는 경로도 시험했습니다. 실물에서 출력과 결선은 확인이 필요합니다.
