# v6.2.0 검증 기록 — 2026-10-30

## 변경

- 기존 `1 kV`가 모델별 명령 검사에서 누락된 문제 수정. 전압·저항은 기본 단위로 환산해 명령을 생성합니다.
- 전압/전류/전력/저항/주파수에 p, n, u/µ/μ, m, k, M, G, T 접두어 지원. m/M 구분, 지수 표기·쉼표 천 단위·유니코드 마이너스 지원.
- 목표값 오른쪽에 측정값 열 추가. 표시 On/Off, Enter/화살표 이동, 단일 열 붙여넣기, 화면 갱신·재계산 중 기록 보존.
- 측정값 입력은 출력 명령과 분리하고, 순차 실행 중에도 입력할 수 있습니다.
- Power Factor 표의 분리된 주파수/전압/전류 열과 역률 방향을 인식합니다. 숫자만 있는 기준번호는 제외합니다.
- `0.5 Lead`, `0.5 Lag`, `1` → `1 LEAD` 처리. 기존 전력 목표 행에도 명시적 Lead/Lag 적용. 역률 행은 전류 그룹 및 턴코일 환산을 따릅니다.
- 잘못된 목표값을 입력한 행에서는 기존 출력 명령을 제거해 설정 확인 상태로 표시합니다.

## 결과

- **74개 자동 시험 통과**: 기존 통신·GUI·전류 그룹·모델별 시험 61개 + 단위·측정값·역률 시험 13개.
- 9가지 배율(기본 단위 포함) × 5가지 단위 계열의 변환과 생성 명령 확인.
- 네 모델 모두 `1 kV` → `OUT 1000 V, 0 HZ` 확인. 범위를 초과하는 전압·전류·저항 거부 확인.
- 사용자가 제공한 15행을 네 모델에서 변환해 `1 LEAD / 0.5 LEAD / 0.5 LAG` 반복 순서, 120 V·10 A·60 Hz, 기준번호 308001 제외 확인.
- 실제 GUI 객체에서 역률 표 붙여넣기, 목표값/역률 동기화, 측정값 보존, Enter의 다음 행 이동 처리, 입력 시 명령 미전송 확인.
- 1280×900, 1060×740에서 주요 버튼 잘림 없음. 표 높이는 각각 398px, 238px. 접기·펼치기 후 설정과 명령 유지.
- 처음 시도한 전체 시험은 실행 환경의 네트워크 제한으로 내부 TCP 접속이 차단되었습니다. 권한 부여 후 같은 모의 장비 시험을 다시 실행하여 전부 통과했습니다.

시험 기록: `work/test_results_v6.2.0.txt`, `work/ui_layout_results.txt`.

실제 Fluke 장비 출력이나 교정 작업은 수행하지 않았습니다. 이번 버전의 클릭 검수는 사용자가 진행하기로 한 범위이며, 자동 검사는 자체 GUI 객체와 모의 통신을 사용했습니다. 측정값은 실행 중인 표에만 저장되며 종료 후 자동 복원은 지원하지 않습니다.
