# 간결한 화면 — v6.3.0

상단에서 모델과 연결 방식을 선택하고 연결합니다. LAN은 IP/포트, RS232는 COM, GPIB는 주소처럼 선택한 방식에 필요한 입력만 표시합니다.

- **상세 설정**: 조회·출력 완료 대기시간, 줄 끝 문자, 랜카드, LAN 진단, 시리얼 속도·흐름 제어, VISA 리소스, 시뮬레이션.
- **출력 끄기 · STBY**: 모든 탭 위에 항상 표시됩니다. 출력 상태 배지도 함께 확인하세요.
- **측정표**: 붙여넣기와 턴코일, 전류 그룹, 시작·일시정지·재개 버튼을 중심으로 배치했습니다.
- **측정값 입력**: 목표값 옆의 기록 열을 켜고 끕니다. Enter로 다음 행에 입력하고, 원하는 행 구간을 드래그한 뒤 Ctrl+C/우클릭으로 복사합니다. [단위·측정값·역률 안내](단위_측정값_역률_사용안내.md)
- **표 편집**: 전체 새로 붙여넣기, 빈 행 추가, 시트 비우기, 예제 불러오기를 모았습니다.
- **범위·그룹 설정**: 시작/종료 행, 전류 분리 기준, 중단점, 명령어 열 표시를 설정합니다.
- **통신 기록·수동 명령**: 창 맨 아래에서 펼칩니다. 화면을 접어도 기록은 계속 자동 저장됩니다.
- **전압·전류·저항·전력 탭**: `설정만 전송`과 `설정 후 출력`을 구분합니다.

화면을 접거나 명령어 열을 숨겨도 입력값과 측정 명령은 유지됩니다. Ctrl+V, F8(다음 행 출력), F9(중단점)도 유지했습니다. 일시정지는 다음 행의 예약 실행을 멈추며, 출력을 끄려면 STBY를 사용하세요.

모델별 통신·출력 범위·턴코일 보상은 [모델별 연결 안내](모델별_연결안내.md)를 참고하세요.

이전 v6.1.0에서는 통신·그룹·모델별 시험 61개와 화면 검수를 완료했습니다. v6.2.0의 변경 내용과 검증 범위는 별도 검증 기록을 참고하세요. 이번 변경의 실제 장비 출력 시험은 수행하지 않았습니다.
